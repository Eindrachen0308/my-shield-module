# X 人材ソーシング エージェント

X (Twitter) のツイートやプロフィール情報を検索し、指定のペルソナに合致する人材をA/B/Cランクでソーシングするエージェントです。

## 機能

- **インタラクティブなペルソナ設定**: 目的・人物像・キーワードを対話形式で設定
- **X検索**: ツイート内容とプロフィール情報から候補者を発見
- **A/B/Cランク評価**:
  - **Aランク**: ペルソナとの合致度が高い（スコア 70-100）
  - **Bランク**: ある程度合致（スコア 40-69）
  - **Cランク**: 合致度は緩いが可能性あり（スコア 10-39）
- **2段階スコアリング**: キーワードマッチング + Claude AIによる高精度評価
- **CSV/JSONエクスポート**: 結果をファイルに出力可能

## セットアップ

### 1. 依存パッケージのインストール

```bash
pip install -r requirements.txt
```

### 2. API キーの設定

`.env.example` をコピーして `.env` を作成し、APIキーを設定します。

```bash
cp .env.example .env
```

#### 必須: X (Twitter) Bearer Token
1. [X Developer Portal](https://developer.x.com/en/portal/dashboard) にアクセス
2. プロジェクトを作成し、Bearer Token を取得
3. `.env` の `X_BEARER_TOKEN` に設定

#### 任意: Anthropic API Key（推奨）
1. [Anthropic Console](https://console.anthropic.com/) にアクセス
2. API キーを取得
3. `.env` の `ANTHROPIC_API_KEY` に設定

> Anthropic API キーを設定すると、Claude AIによる高精度なペルソナマッチング評価が利用できます。未設定の場合はキーワードベースの簡易評価のみとなります。

### 3. 実行

```bash
python main.py
```

## 使い方

### 1. ペルソナ設定

エージェントが以下の質問を対話形式で聞きます：

| 質問 | 内容 | 例 |
|------|------|-----|
| Q1. 目的 | ソーシングの目的 | 正社員採用、業務委託 等 |
| Q2. 人物像 | 求める人物の説明 | Pythonが得意なバックエンドエンジニア |
| Q3. 必須キーワード | 必ずマッチすべきキーワード | Python, 機械学習 |
| Q4. 推奨キーワード | あると望ましいキーワード | AWS, Docker |
| Q5. 加点キーワード | あれば加点となるキーワード | OSS貢献, 登壇経験 |
| Q6. エリア | 希望勤務地 | 東京 |
| Q7. フォロワー数 | 最小フォロワー数の目安 | 500 |

### 2. 検索・評価

設定されたペルソナに基づいてXを検索し、候補者を自動的にランク付けします。

### 3. 結果確認

ランク別に候補者が一覧表示されます。以下のアクションが可能です：
- 候補者の詳細表示
- CSV/JSONエクスポート
- 条件を変えて再検索

## スコアリングの仕組み

### キーワードスコアリング
- 必須キーワード1つにつき: +30点
- 推奨キーワード1つにつき: +15点
- 加点キーワード1つにつき: +5点
- エリアマッチ: +5点

### LLMスコアリング（Anthropic API使用時）
Claude AIがプロフィールとツイート内容を総合的に分析し、以下を評価：
- キーワードの文脈的なマッチ度
- スキルの関連性と転用可能性
- 発信内容から推測される専門性
- ポテンシャルの高さ
